# Отсечка

Интерактивный сайт к докладу «Бюджетное правило в России как институт: почему частые изменения снижают доверие к фискальной политике» для VIII Горчаковских чтений (РАНХиГС, Санкт-Петербург, ноябрь 2026).

## Что на странице

1. **Главный график**: цена отсечения по годам с 2017 по 2027 и средняя цена Urals, с подсказками по каждому году.
2. **Механизм**: как работает правило при дорогой и дешёвой нефти, с анимацией потоков в ФНБ и из него.
3. **Хронология**: восемь решений по правилу с закреплённой панелью параметров.
4. **Главный тезис**: текст подсвечивается по словам при прокрутке.
5. **Три цены для 2027 года**: 61,2 $, 58 $ и 50 $.
6. **2026 год**: горизонтальная лента событий, которая листается вертикальной прокруткой.
7. **Запас прочности**: ликвидная часть ФНБ в процентах ВВП.
8. **Симулятор**: цена нефти, цена отсечения, курс и шесть сценариев из реальной истории.
9. **Выводы и FAQ.**

## Перед публикацией

Откройте `src/content/site.ts` и впишите имя, кафедру и научного руководителя. Пустые поля на сайте не показываются.

Все цифры лежат в `src/data/rule.ts`. Если до конференции Госдума окончательно примет бюджет на 2027 год, поправьте там подпись «проект». Источники к цифрам собраны в `src/data/sources.ts`: на сайте они не выводятся, но пригодятся для доклада и ответов на вопросы.

## Запуск

```bash
npm install
npm run dev      # локально на http://localhost:5173
npm run build    # сборка в папку dist
```

## Деплой на Vercel

1. На vercel.com нажмите **Add New → Project** и выберите этот репозиторий.
2. Vercel сам определит Vite. Настройки уже лежат в `vercel.json`: команда `npm run build`, папка `dist`.
3. Нажмите **Deploy**. После этого каждый пуш в `main` будет обновлять сайт.

## Стек

Vite, React, TypeScript, Tailwind CSS 4, Framer Motion, d3-scale и d3-shape для графиков, иконки Phosphor, шрифты Manrope и Geist Mono (подключаются локально, без внешних запросов).

## Дизайн

Визуальная система следует скиллу `landing-page-design` из [elayadesign/ai-design-skills](https://github.com/elayadesign/ai-design-skills): шкала шрифтов и отступов, кривая анимации, плавающая навигация, проявление разделов при прокрутке, учёт настройки «уменьшить движение». Скилл лежит в `.claude/skills/landing-page-design`, поэтому Claude Code подхватит его при следующей работе с репозиторием.
